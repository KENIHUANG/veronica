# Veronica: 生发剂实验室 (Godot 4.3+)

第一人称的生化危机风格喜剧恐怖小游戏,约 20~40 分钟。
用 Godot 4.3 或更新版本打开本文件夹,按 F5 运行。(不需要任何外部资源。)

## 操作
WASD 移动 · Shift 奔跑(会发出声音) · 鼠标 视角 · E 互动 · F 手电 · Tab 背包 · H 用喷雾恢复 · Q 扣动空枪(引开 Boss) · Esc 暂停

## 通关流程(剧透)
1. 大厅:拿修女雕像手里的**镊子** → 雕像苏醒追你
2. 进右侧厕所 → **镜子**(秃头大叔,镜子碎裂)→ 捡**镜子碎片**
3. 雕像走近时对它按 E,**连按 E** 刺进胸口 → 按**头顶按钮**拿到**门禁卡**
4. 厕所 4 号隔间:撕碎的照片 → 背包里**拼合**(背面写着 2021.2.3)
5. 洗手池(左数第 1 个)用镊子夹出头发里的钥匙 → 任意水龙头冲洗 → **办公室钥匙**
6. 办公室:保险箱密码 **2021.2.3**(输入 20210203 或 2021.2.3)→ 日记 + 空枪 → 收音机事件
7. 用门禁卡开实验室 → Boss 登场。他会定期走出后门(约 28 秒),趁那时操作
8. 配方笔记(缺第 5 行)+ 电脑(便利贴密码 SARAH0203)→ 调配台:**5 / 30 / 40 / 20 / 5**(合计 100)
9. 把完美生发剂交给弟子1号 → 结局

## 调试键(仅在编辑器里运行时有效)
F2 传送到下一个房间 · F3 获得关键道具并开门 · F4 已知配方 · F5 回满血

## 代码结构
- `autoload/gs.gd` 全局状态(flag、背包、血量、检查点、存档)  `ui.gd` 全部界面  `sfx.gd` 程序化音效
- `scripts/main.gd` 游戏流程  `player.gd` 玩家  `statue.gd` 修女雕像  `boss.gd` 弟子1号 AI
- `scripts/rooms/` 四个房间(hall / restroom / office / lab),每个房间一个 `build()`
- `scripts/wb.gd` 搭建小工具  `mats.gd` 程序化贴图  `nav.gd` 路点寻路  `interactable.gd` 通用互动物

## 细节与建模(v2)
- **雕像**:带褶皱的长袍、头巾面纱、空洞眼眶、会张开的下颌和牙齿、念珠、手指夹着镊子、裂纹和苔藓。拿走镊子后她**先张嘴尖叫约 2.6 秒**(玩家被锁定、屏幕抖动、灯狂闪、眼睛亮红),然后走下基座抽搐着追你,追击中还会低吼。
- **镜子是真的平面镜**:镜子里是一台镜像摄像机拍到的真实房间。镜中人影(Veronica / 秃头大叔)只存在于"镜像图层",主摄像机永远看不到,所以只有你**照镜子的时候才有建模**。事件里人影会慢半拍,然后换成戴眼镜、眼眶空洞的秃头大叔,他扑向玻璃,镜子碎裂。
- **马桶、洗手台**:用 CSG 挖出真正的碗和盆(座圈、翻起的马桶盖、水箱、冲水键、进水管、水渍环),水龙头带双把手,下方有弯管。1 号马桶被头发堵死并漫过碗沿。另有卷纸、地漏、垃圾桶、隔间插销。
- **蟑螂**:椭球身体、头、护胸甲、触角会摆动、六条腿。
- **Boss / 鬼魂**:用胶囊和椭球拼的人形(`scripts/humanoid.gd`),Boss 驼背、手持发光注射器。

- **v2.1 细节**:试剂瓶(玻璃 + 发光液体 + 软木塞 + 标签)、锥形烧瓶、CRT 显示器(屏幕上有字)、办公椅、键盘;实验室加了一盏不闪的冷色底光,不会再彻底漆黑;便利贴改成贴在墙上的大黄纸(带图钉,字写在纸上),互动范围大了很多。

- **v2.2 大厅**:墙裙与压条、顶线、三个门框和门牌、挂画(有的歪了)、带罩的吊灯、完整的接待台(嵌板、铃、电话、登记簿、台灯、信格墙、停摆的时钟)、铁腿木长椅、枯萎的盆栽、灭火器、木箱、散落的纸、墙角蜘蛛网、漂浮的灰尘;入口换成门框加微敞的双扇门,漏进蓝色月光,上方有绿色 EXIT 灯。

- **v2.3 Boss / 厕所 / 办公室**:Boss 有充血的眼睛、眼袋、凹陷的脸颊、胡茬、咧开的嘴和牙、乱翘的灰发、沾着化学污渍的白大褂(口袋、笔、胸牌)、绿手套,追击时会抽搐。厕所有霉斑、锈水痕、天花板渗水、掉瓷砖的墙面、皂液器、擦手纸盒、烘手机、拖把桶、滴水、通风格栅、地面裂缝与散落的头发和卷纸。办公室有白板(化学式)、软木板(图钉和红线)、百叶窗、书柜、挂钟(停在 2:03)、证书、地毯,收音机挪到了北墙。

- **v2.4 结局**:电影式演出(上下黑边)。交付药剂后 Boss 把药抹在头顶,头发一簇一簇真的长出来(金色光点、灯光不再闪烁、镜头缓缓推近);博士的鬼魂在他旁边渐渐显形,和你们说话(如果你拼好了合照,他会提到 Sarah),说出那句"洗完澡,记得清理水槽",然后化作光点消散;Boss 走出后门,门外透进破晓的光;最后切到黎明的河边:河水清了,那个有小胡子的小女孩把硬币抛向空中——"你猜?"。尾声字幕后出 THE END。

## 语言与手机端(v3)
- **中英文**:标题和暂停菜单里的「语言 / Language」按钮可随时切换,设置会保存;首次启动按系统语言自动选择。所有文案以中文原文为键,英文在 `scripts/en_strings.gd`;新增文案时用 `L.t("中文")`(或带占位符的 `L.f("... {n} ...", {"n": 1})`)包一下,并在 `en_strings.gd` 里补英文。
- **触控**:手机上自动启用(也可在标题/暂停菜单里手动开关)。左半屏拖动 = 浮动摇杆;右半屏拖动 = 转视角;右下红色大按钮 = 互动(QTE 连点);「奔跑」按住;顶部小按钮 = 暂停 / 物品 / 手电 / 喷雾 / 空枪。按钮通过合成键盘事件驱动原有逻辑。
- **渲染器**:桌面默认 Forward+;手机和网页使用 Compatibility(已在项目设置里指定),镜子、阴影、CSG 都已验证可用。
- 发布到 GitHub / Steam / 手机的步骤见 `docs/PUBLISHING.md`。

## 画面风格(v6)

## 换成真正的美术:素材替换槽(不用改代码)
把文件放进对应路径,重新打开 Godot(会自动导入),游戏就会优先用它;删掉文件就回到程序化模型。实现见 `scripts/asset_slots.gd`。

**模型** `assets/models/<名字>.glb`(或 `.gltf`)
- 约定:1 单位 = 1 米;**朝向 -Z**;脚底/底面在原点。
- 人物:`veronica`(镜中倒影)、`mirror_ghost`(镜中秃头大叔)、`boss`(弟子1号)、`doctor_ghost`(博士鬼魂,会自动变成半透明蓝色)、`girl`(结局小女孩;游戏里会再缩放到 0.62)。
- 其他:`statue_nun`(修女石像;眼睛红光、胸口、头顶按钮、镊子仍用程序化的功能件)、`toilet`、`sink`、`mannequin`(带底座的人体模型)、`wig_comb`、`wig_afro`、`wig_twin`(假发,原点放在塑料人头中心)。
- 人物模型带骨骼时,会按骨骼名(Mixamo 的 `mixamorig:RightHand`、Blender 的 `hand.R` 等)自动挂点,Boss 手里的针会跟着手走;模型自带动画时自动循环播放名字含 `idle` 的那段。
- 没有骨骼的人物模型也能用,只是代码里的抬手、歪头等姿势不会作用到模型上。
- 物体会按包围盒自动生成碰撞体。

**贴图** `assets/textures/<材质名>/color.jpg`,可选 `normal.jpg`、`roughness.jpg`(png/webp 也行)
- 材质名:`wallpaper`(大厅墙纸)、`wood`、`deskwood`、`concrete`、`plaster`、`tile`(厕所墙砖)、`tile_floor`、`rust`、`steel`、`labtile`、`labwall`、`carpet`、`stone`。
- 贴图用三平面映射,无需 UV;无缝贴图效果最好。

**去哪里找素材**(都要自己确认授权,商用前尤其注意)
- 模型:[Quaternius](https://quaternius.com)、[Kenney](https://kenney.nl)(CC0 低模,风格很搭 PS1 画面);[Poly Haven](https://polyhaven.com/models)(写实、CC0)。
- 人物:[Mixamo](https://www.mixamo.com)(免费带骨骼和动画,可在 Adobe 条款下用于游戏);[MakeHuman](http://www.makehumancommunity.org)(CC0 导出);Meshy、Tripo 等 AI 生成(务必看清各自的商用授权,导出后检查面数和朝向)。
- 贴图:[ambientCG](https://ambientcg.com)、[Poly Haven](https://polyhaven.com/textures)(CC0 PBR)。
- 用到的素材请登记在 `CREDITS.md`。

**用 Blender 导出 GLB**
1. 单位:场景比例 1.0(米)。人物站在原点,脸朝 Blender 的 **-Y**(Godot 里会变成 -Z)。
2. 应用变换:选中模型 → `Ctrl+A` → All Transforms。
3. 文件 → 导出 → glTF 2.0:格式选 **glTF Binary (.glb)**,勾选 +Y Up,包含 Selected Objects、Apply Modifiers;带骨骼动画的勾选 Animation。
4. 改名为上面的槽名,放进 `assets/models/`。
5. 面数建议:人物 5k~20k 三角面;小道具 2k 以内(手机端也要跑)。

**音频**:`autoload/sfx.gd` 里的 `streams[...]` 换成 `load("res://assets/xxx.ogg")` 即可(音效替换槽计划在 C 部分做)。
