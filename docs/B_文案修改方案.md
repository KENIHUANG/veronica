# B. 文案修改方案(草案,待确认后再动代码)

> 本文件只是方案,游戏内文案**尚未修改**。确认方向后,我再逐段改写、同步 `scripts/en_strings.gd`、重新生成 `docs/script_all_zh.md`,并跑 `tests/run_all.sh`。

## 1. 统一口吻(建议)

三种声音,各管各的:

| 场合 | 口吻 | 规则 |
|---|---|---|
| 序幕、目标、物品说明、调查文本 | **环保调查报告腔**:一本正经、带编号和数据,越往后越荒诞 | 句子完整、克制;笑点靠"认真地写出离谱的事" |
| 恐怖段落(石像、镜子、柜子、Boss 追击) | **短、压抑、留白** | 每句不超过 12 字;不解释、不吐槽 |
| 日记、Boss 独白、鬼魂告别 | **人物自己的声音** | 博士:从骄傲到崩溃;弟子1号:委屈+偏执;鬼魂:释然 |

当前最大的问题是这三种声音混在一起:恐怖瞬间后面紧跟吐槽(例:镜子碎后的"很合理。"),日记里网络用语、中英混杂和正经叙述交替。

## 2. 发现的设定矛盾(需要你拍板)

1. **"我们试了十年"**(弟子1号,结局)vs. 日记里博士 2025.3.14 才在网上认识学徒1。→ 建议改成"我们试了整整一年",或把相识提前。
2. **Boss 独白"那是2000年……我还是个学生"**:那他现在约 40 多岁;"爷孙恋"笑点仍成立。保留即可,只是确认。
3. **鬼魂"我研究了十五年的婚姻……都没算出这个比例"**:意思不清(是在说婚姻也需要配比?)。→ 建议:"十五年婚姻我都没算明白,这个比例倒让你算出来了。"
4. **"空腔手枪"**不是常用词。→ 建议改为"空枪"或"没有子弹的手枪"。
5. **序幕"为了守护这个小女孩性别的公正性"**语义别扭。→ 建议:"有些事,不该由一枚硬币决定。你决定去了结这一切。"
6. **镜子碎后"(是一个容貌焦虑的科学家鬼魂打碎的。很合理。)"**:打断恐怖节奏。→ 建议删掉,或挪到之后"查看镜子"的调查文本里(那时紧张感已过,适合冷幽默)。

## 3. 日记:人物弧线(骄傲 → 偏执 → 崩溃 → 遗言)

必须保留的信息:日期 2021.2.3(间接:合照背面,保险箱密码)、Sarah、"光头"、米诺地尔、学徒1、全身长毛、"Remember to clean the sink after you shower."

**2026.3.15(原,节选)**

## 4. Boss 独白(保留原意,只调节奏)

原意全部保留:老师没错、世界糟糕、2000 年掉发、女神说接受不了爷孙恋、老师驾鹤西去、"你也有很多头发,是吗?"

> (他慢慢转过头,盯着你。)
> ……你的头发,很多啊。
