## 附:可玩性(先记下,文案改完再聊)

现在流程是"找道具 → 解谜 → 躲 Boss"一条线,玩的东西确实少。几个不用大改结构、又和新剧情贴合的点子:

- **排污管道追逐**:读完检测报告后,在实验室后门发现排污阀门。关阀门会惊动 Boss,触发一段追逐,成功后河水"本轮排放"停止。把"40 天一次"的设定变成玩法。
- **头发计时**:Veronica 在实验室待太久,手背开始长毛(画面边缘出现汗毛),逼玩家加快速度;喷雾能暂时压下去。恐怖 + 好笑。
- **收集品:镇民的委托信**:散落在各处的 5 封信(理发店老板、秃头的小学生、被假发店抢生意的人……),全收集解锁一段额外结局台词。增加探索动力,也让小镇更真实。
